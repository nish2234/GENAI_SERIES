# Google ADK — quick notes

- ADK = Agent Development Kit, Google's open-source framework for building agents.
- Python 2.0 went GA on May 19, 2026. 2.0 adds graph-based workflows, dynamic workflows and collaborative agents.
- `adk web` gives a dev UI: Chat, Sessions, State, Events, Trace, Artifacts, Eval.
- Tools: function tools, built-in tools (Google Search, code execution), OpenAPI tools, MCP tools,
  and third-party tools from CrewAI and LangChain.
- Agents can call other agents as tools with `AgentTool`.
