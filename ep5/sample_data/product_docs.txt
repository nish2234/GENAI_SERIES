ACME TASKFLOW — PRODUCT DOCUMENTATION
=======================================

OVERVIEW
--------
ACME TaskFlow is a project management and team collaboration platform designed for teams of 5 to 500 people. TaskFlow combines task tracking, real-time messaging, document sharing, and automated workflows into a single unified workspace. The platform is available as a web application, desktop app (Windows and macOS), and mobile app (iOS and Android).

GETTING STARTED
---------------
To get started with TaskFlow, create an account at app.acmetaskflow.com. New users can start a 14-day free trial of the Pro plan with no credit card required. After signup, you will be guided through a setup wizard that helps you create your first workspace, invite team members, and configure your first project board.

PRICING PLANS
-------------
TaskFlow offers three pricing tiers:
- Free Plan: Up to 5 users, 3 projects, 1 GB storage, basic task management.
- Pro Plan ($12/user/month): Unlimited users and projects, 50 GB storage, advanced workflows, time tracking, Gantt charts, and priority support.
- Enterprise Plan ($28/user/month): Everything in Pro plus SSO/SAML, advanced security controls, audit logs, custom integrations, dedicated account manager, and 99.9% uptime SLA.
All plans include real-time messaging, file sharing, and mobile access. Annual billing saves 20%.

TASK MANAGEMENT
---------------
Tasks in TaskFlow can be organized into projects, and projects into workspaces. Each task has the following fields: title, description, assignee, due date, priority (Low, Medium, High, Urgent), status (To Do, In Progress, In Review, Done), tags, and attachments. Tasks support subtasks (up to 3 levels deep), comments with @mentions, and file attachments up to 100 MB each. Tasks can be viewed in Board view (Kanban), List view, Calendar view, or Timeline view (Gantt chart, Pro plan and above).

AUTOMATED WORKFLOWS
--------------------
TaskFlow's automation engine lets you create rules that trigger actions based on events. For example: "When a task is moved to Done, send a Slack notification to the project channel" or "When a task is past due by 2 days, reassign to the team lead and escalate priority to Urgent." Automations are built using a visual drag-and-drop editor with no coding required. Pro plan users can create up to 50 automations per workspace. Enterprise users get unlimited automations plus access to the Workflow API for custom integrations.

INTEGRATIONS
------------
TaskFlow integrates with over 40 third-party tools including: Slack, Microsoft Teams, Google Drive, Dropbox, GitHub, GitLab, Jira (for migration), Figma, Notion, Zapier, and Salesforce. Integrations are managed through the Integrations page in workspace settings. Most integrations use OAuth for secure authentication. Enterprise customers can build custom integrations using the TaskFlow REST API, which supports full CRUD operations on tasks, projects, users, and comments.

SEARCH AND FILTERS
------------------
TaskFlow includes a powerful search engine that indexes all task titles, descriptions, comments, and attached document content. Search supports full-text search, boolean operators (AND, OR, NOT), and field-specific filters (e.g., assignee:jane, priority:high, due:<2025-03-01). Search results can be saved as custom views and shared with team members. The search index updates in real time — new tasks and comments are searchable within seconds of creation.

DATA EXPORT AND BACKUP
-----------------------
Workspace administrators can export all project data in CSV or JSON format from the Admin panel. Exports include tasks, comments, attachments metadata, and user activity logs. Full data exports are available once per 24 hours and typically complete within 5 minutes for workspaces with under 10,000 tasks. TaskFlow performs automated daily backups with 30-day retention. Enterprise customers can configure custom backup schedules and export to their own S3-compatible storage.

RETURN AND REFUND POLICY
-------------------------
TaskFlow subscriptions can be cancelled at any time from the Billing page. When you cancel, your plan remains active until the end of the current billing period. Refunds are available within 14 days of an initial purchase or plan upgrade. To request a refund, contact support@acmetaskflow.com with your workspace ID and reason for the refund. Refunds are processed within 5-7 business days. The Free plan has no charges and requires no cancellation.
